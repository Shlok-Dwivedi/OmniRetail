                         These ratings are my own opinion after doing this assignment, they are not any standard
                         score.

                         Usability: Excel is the easiest because no code is needed and a chart is ready in a few
                         clicks. Seaborn and Plotly Express need only one or two lines for most charts and they
                         work directly with the DataFrame. Matplotlib needs the most lines, for example the value
                         labels on the bars and the text in the centre of the donut had to be added separately.

                         Flexibility: Matplotlib gives control over every part of the figure, and Seaborn charts can
                         still be customized with plt commands because Seaborn is built on Matplotlib. Plotly has
                         many chart types and interactivity, but changing small things needs update_layout and
                         takes time to learn. Excel is limited to what is available in its menus. Seaborn has no pie
                         or donut function, so Matplotlib or Plotly is needed for those.

                         Visual appeal: The default Matplotlib charts look plain. Seaborn gives better colors and
                         style without any extra work. Plotly looks the most modern and its hover, zoom and
                         legend click make the chart easy to explore. Excel charts look clean and are good for
                         reports, but they are static once pasted in a document.

## Creating the Dataset

A dataset of 150 employees is created using numpy with a fixed seed (like in Lab 6), so the same data comes every time the notebook is run. It has numerical columns (age, salary, performance_score) for the histograms and box plots, and categorical columns (department, gender, city, salary_category) for the bar, pie and donut charts.
#creating the employee dataset
np.random.seed(33)
n = 150

departments = ["IT", "HR", "Sales", "Finance", "Marketing"]
dept_base = {"IT": 60000, "HR": 42000, "Sales": 48000, "Finance": 55000, "Marketing": 46000}

df = pd.DataFrame({
    "employee_id": range(1001, 1001 + n),
    "gender": np.random.choice(["Male", "Female"], n, p=[0.55, 0.45]),
    "age": np.random.normal(32, 6, n).clip(22, 58).astype(int),
    "department": np.random.choice(departments, n, p=[0.30, 0.12, 0.25, 0.15, 0.18]),
    "city": np.random.choice(["Nagpur", "Pune", "Mumbai", "Nashik"], n, p=[0.35, 0.30, 0.25, 0.10]),
    "performance_score": np.random.normal(3.4, 0.7, n).clip(1, 5).round(1)
})

#salary depends on department and age
df["salary"] = df["department"].map(dept_base) + (df["age"] - 22) * 1200 + np.random.normal(0, 6000, n)
df["salary"] = ((df["salary"] / 500).round() * 500).astype(int)

#3 oldest employees get a much higher salary (senior management), this creates outliers
senior = df.nlargest(3, "age").index
df.loc[senior, "salary"] = df.loc[senior, "salary"] + 40000
### Creating salary_category column
def categorize_salary(salary):
    if salary < 50000:
        return "Low"
    elif salary <= 75000:
        return "Medium"
    else:
        return "High"

## Part E — Comparison of the Visualization Tools

| Feature | Matplotlib | Seaborn | Plotly | Excel |
|---|---|---|---|---|
| Used in this assignment for | histogram, box plot, bar, pie, donut | histogram, box plot, grouped bar | bar, grouped bar, pie, donut | bar, pie, donut |
| Code needed | Yes, the most lines | Yes, short | Yes, short | No code |
| Interactive (hover, zoom) | No | No | Yes | Very limited |
| Pie and donut | Yes (plt.pie, donut with wedgeprops) | No pie function | Yes (px.pie, hole=0.4 for donut) | Yes (Pie, Doughnut) |
| Histogram and box plot | Yes | Yes (easiest, has kde and hue) | Yes (px.histogram, px.box), not used here | Yes (Excel 2016 or later) |
| New or changed data | Re-run the code | Re-run the code | Re-run the code | Manual work |
| Best suited for | detailed, custom figures | quick statistical plots | interactive charts, dashboards | quick charts for reports, no coding |

### Rating (out of 5)

| Criteria | Matplotlib | Seaborn | Plotly | Excel |
|---|---|---|---|---|
| Usability | 3 | 4 | 4 | 5 |
| Flexibility | 5 | 4 | 4 | 2 |
| Visual appeal (default look) | 2 | 4 | 5 | 4 |

These ratings are my own opinion after doing this assignment, they are not any standard score.

**Usability:** Excel is the easiest because no code is needed and a chart is ready in a few clicks. Seaborn and Plotly Express need only one or two lines for most charts and they work directly with the DataFrame. Matplotlib needs the most lines, for example the value labels on the bars and the text in the centre of the donut had to be added separately.

**Flexibility:** Matplotlib gives control over every part of the figure, and Seaborn charts can still be customized with plt commands because Seaborn is built on Matplotlib. Plotly has many chart types and interactivity, but changing small things needs update_layout and takes time to learn. Excel is limited to what is available in its menus. Seaborn has no pie or donut function, so Matplotlib or Plotly is needed for those.

**Visual appeal:** The default Matplotlib charts look plain. Seaborn gives better colors and style without any extra work. Plotly looks the most modern and its hover, zoom and legend click make the chart easy to explore. Excel charts look clean and are good for reports, but they are static once pasted in a document.

### Conclusion

Histograms and box plots were easiest in Seaborn, since the kde, hue and grouping by category are just one argument each, and the IQR calculation in pandas confirmed the outliers shown by the box plot. Matplotlib is better when more control is needed, such as the mean and median lines on the histogram or the text in the centre of the donut. For bar, pie and donut charts Plotly was the quickest (a donut is just hole=0.4) and it is interactive. Excel is good for quick charts without coding but it is less flexible and the work is manual. Using the right tool for the kind of chart and the audience gives the best result, so in practice these tools are used together.
